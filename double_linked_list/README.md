# DoubleLinkedList (двусвязный список)

## Поля для реализации

- `__head`: ссылка на первый узел списка.
- `__tail`: ссылка на последний узел списка.
- `__count`: количество элементов списка.

## Node

- `data`: значение узла.
- `next`: ссылка на следующий узел.
- `prev`: ссылка на предыдущий узел.

## Интерфейс

1. `show() -> list[Any]` - возвращает элементы списка в виде Python-списка.  
   Лучший `O(n)`, средний `O(n)`, худший `O(n)`.
2. `add_last(data: Any) -> None` - добавляет элемент в конец списка.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
3. `add_head(data: Any) -> None` - добавляет элемент в начало списка.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
4. `delete_first() -> Node | None` - удаляет первый узел списка.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
5. `delete_last() -> Node | None` - удаляет последний узел списка.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
6. `insert(position: int, data: Any) -> None` - вставляет элемент на указанную позицию.  
   Лучший `O(1)`, средний `O(n)`, худший `O(n)`.
7. `get(position: int) -> Node` - возвращает узел по позиции, начиная обход с ближайшего края.  
   Лучший `O(1)`, средний `O(n)`, худший `O(n)`.
8. `remove(data: Any) -> Node | None` - удаляет первое вхождение элемента и возвращает удаленный узел.  
   Лучший `O(1)`, средний `O(n)`, худший `O(n)`.
9. `find(target: Any) -> Node | None` - ищет узел по значению.  
   Лучший `O(1)`, средний `O(n)`, худший `O(n)`.
10. `count() -> int` - возвращает количество элементов.  
    Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
11. `is_empty() -> bool` - проверяет список на пустоту.  
    Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
