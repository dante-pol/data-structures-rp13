# Stack (стек, Last In First Out)

## Поля для реализации

- `__top`: ссылка на вершину стека.
- `__count`: количество элементов стека.

## Node

- `data`: значение узла.
- `prev`: ссылка на предыдущий узел.

## Интерфейс

1. `push(data: Any) -> None` - добавляет элемент на вершину стека.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
2. `pop() -> Any` - удаляет и возвращает элемент с вершины стека.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
3. `peek() -> Any` - возвращает элемент с вершины без удаления.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
4. `is_empty() -> bool` - проверяет стек на пустоту.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
