# HashMap (хеш-таблица)

## HashMap1: линейное разрешение коллизий

### Поля для реализации

- `__keys`: массив ключей.
- `__memory`: массив значений.
- `__count`: количество сохраненных пар ключ-значение.

### Интерфейс

1. `add(key: Any, value: Any) -> None` - добавляет новую пару или обновляет значение по ключу.  
   Лучший `O(1)`, средний `O(1)`, худший `O(n)`.
2. `get(key: Any) -> Any` - возвращает значение по ключу.  
   Лучший `O(1)`, средний `O(1)`, худший `O(n)`.
3. `remove(key: Any) -> Any` - удаляет пару по ключу и возвращает значение.  
   Лучший `O(1)`, средний `O(1)`, худший `O(n)`.
4. `count() -> int` - возвращает количество элементов.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
5. `get_memory() -> list[Any]` - возвращает внутренний массив значений для тестов.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.

## HashMap2: цепочное разрешение коллизий

### Поля для реализации

   Лучший `O(1)`, средний `O(1)`, худший `O(n)`.
4. `count() -> int` - возвращает количество элементов.

5. `get_memory() -> list[Any]` - возвращает внутренний массив бакетов для тестов.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
