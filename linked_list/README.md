# LinkedList (односвязный список)

## Поля для реализации

- `__head`: ссылка на первый узел списка.
- `__count`: количество элементов списка.

## Node

- `data`: значение узла.
- `next`: ссылка на следующий узел.

## Интерфейс

1. `show() -> list[Any]` - возвращает элементы списка в виде Python-списка.  
   Лучший `O(n)`, средний `O(n)`, худший `O(n)`.
2. `add_last(data: Any) -> None` - добавляет элемент в конец списка.  
   Лучший `O(n)`, средний `O(n)`, худший `O(n)`.
3. `add_head(data: Any) -> None` - добавляет элемент в начало списка.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
4. `insert(position: int, data: Any) -> None` - вставляет элемент на указанную позицию.  
   Лучший `O(1)`, средний `O(n)`, худший `O(n)`.
5. `get(position: int) -> Node | None` - возвращает узел по позиции.  
   Лучший `O(n)`, средний `O(n)`, худший `O(n)`.
6. `remove(data: Any) -> Node | None` - удаляет первое вхождение элемента и возвращает удаленный узел.  
   Лучший `O(1)`, средний `O(n)`, худший `O(n)`.
7. `find(data: Any) -> Node | None` - ищет узел по значению.  
   Лучший `O(1)`, средний `O(n)`, худший `O(n)`.
8. `count() -> int` - возвращает количество элементов.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
9. `is_empty() -> bool` - проверяет список на пустоту.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
