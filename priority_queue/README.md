# PriorityQueue (приоритетная очередь)

## Поля для реализации

- `__heap`: бинарная куча, которая хранит элементы по приоритету.


## Интерфейс PriorityQueue

1. `enqueue(priority: int, data: Any) -> None` - добавляет элемент с приоритетом.  
   Лучший `O(1)`, средний `O(log n)`, худший `O(log n)`.
2. `dequeue() -> Any` - извлекает элемент с минимальным приоритетом.  
   Лучший `O(1)`, средний `O(log n)`, худший `O(log n)`.
3. `peek() -> Any` - возвращает элемент с минимальным приоритетом без удаления.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
4. `is_empty() -> bool` - проверяет очередь на пустоту.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
