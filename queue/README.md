# Queue (очередь, First In First Out)

## Поля для реализации

- `__head`: ссылка на первый элемент очереди.
- `__tail`: ссылка на последний элемент очереди.
- `__count`: количество элементов очереди.

## Node

- `data`: значение узла.
- `prev`: ссылка на следующий элемент в направлении выхода из очереди.

## Интерфейс

1. `enqueue(data: Any) -> None` - добавляет элемент в конец очереди.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
2. `dequeue() -> None` - удаляет элемент из начала очереди.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
3. `peek() -> Any` - возвращает первый элемент без удаления.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
4. `is_empty() -> bool` - проверяет очередь на пустоту.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
