# Deque (двусторонняя очередь)

## Поля для реализации

- `__head`: ссылка на первый элемент очереди.
- `__tail`: ссылка на последний элемент очереди.
- `__count`: количество элементов.

## Node

- `data`: значение узла.
- `next`: ссылка на следующий узел.
- `prev`: ссылка на предыдущий узел.

## Интерфейс

1. `enqueue(data: Any) -> None` - добавляет элемент в хвост очереди.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
2. `enqueue_head(data: Any) -> None` - добавляет элемент в голову очереди.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
3. `dequeue() -> Any | None` - извлекает элемент из головы очереди.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
4. `dequeue_tail() -> Any | None` - извлекает элемент из хвоста очереди.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
5. `peek() -> Any` - возвращает значение в голове без удаления.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
6. `peek_tail() -> Any` - возвращает значение в хвосте без удаления.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
7. `is_empty() -> bool` - проверяет очередь на пустоту.  
   Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
