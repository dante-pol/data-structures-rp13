# List (динамический массив)

## Поля для реализации

- `__memory`: внутренний массив фиксированной текущей вместимости.
- `__size`: текущая вместимость выделенной памяти.
- `__count`: количество добавленных элементов.

## Интерфейс

1. `add(data: Any) -> None` - добавляет элемент в конец массива.  
   Лучший `O(1)`, средний `O(1)`, худший `O(n)`.
2. `add_head(data: Any) -> None` - добавляет элемент в начало массива со сдвигом остальных элементов.  
   Лучший `O(1)`, средний `O(n)`, худший `O(n)`.
3. `insert(data: Any, insert_index: int) -> None` - вставляет элемент на указанную позицию.  
   Лучший `O(1)`, средний `O(n)`, худший `O(n)`.
4. `remove(data: Any) -> None` - удаляет первое вхождение элемента.  
   Лучший `O(1)`, средний `O(n)`, худший `O(n)`.
5. `pop(pop_index: int) -> None` - удаляет элемент по индексу.  
   Лучший `O(1)`, средний `O(n)`, худший `O(n)`.
6. `count(item: Any) -> int` - возвращает количество вхождений элемента.  
   Лучший `O(1)`, средний `O(n)`, худший `O(n)`.
7. `find(item: Any) -> int` - возвращает индекс первого найденного элемента или `-1`.  
   Лучший `O(1)`, средний `O(n)`, худший `O(n)`.
8. `sort(order_by, key) -> None` - сортирует массив пузырьковой сортировкой.  
   Лучший `O(n^2)`, средний `O(n^2)`, худший `O(n^2)`.
9. `reverse() -> None` - разворачивает элементы массива.  
   Лучший `O(n)`, средний `O(n)`, худший `O(n)`.
10. `is_empty() -> bool` - проверяет массив на пустоту.  
    Лучший `O(1)`, средний `O(1)`, худший `O(1)`.
